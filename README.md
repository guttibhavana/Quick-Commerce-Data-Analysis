# 🚀 Quick Commerce Data Analysis

A comprehensive **Exploratory Data Analysis (EDA)** project on a Quick Commerce dataset using **Python**. This project focuses on cleaning raw data, analyzing business performance, answering real-world business questions, and creating insightful visualizations to support data-driven decision making.

---

## 📌 Project Overview

Quick commerce companies generate massive amounts of operational data every day. This project analyzes order, delivery, customer, and revenue data to uncover valuable business insights such as revenue trends, delivery performance, customer satisfaction, and operational efficiency.

---

## 🎯 Objectives

* Clean and preprocess the dataset
* Handle missing values and outliers
* Perform Exploratory Data Analysis (EDA)
* Answer business-driven analytical questions
* Create informative visualizations
* Build a mini analytics dashboard

---

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* Scikit-learn

---

## 📂 Dataset Features

The dataset contains information such as:

* Order ID
* Company
* City
* Customer Age
* Product Category
* Order Value
* Items Count
* Delivery Time
* Customer Rating
* Delivery Partner Rating
* Discount Applied
* Distance (Km)

---

## 🧹 Data Cleaning

The following preprocessing steps were performed:

* Removed missing values
* Filled null values using mode and group-wise mean
* Removed/handled outliers
* Converted data types
* Rounded numerical values
* Saved the cleaned dataset for further analysis
